# fingerprintchrome (npm)

[English](../README.md) · [简体中文](../README.zh-CN.md)

Stealth Chromium for Node.js — Playwright / Puppeteer drop-in.

```js
import { launch } from "fingerprintchrome";
// or: import { launch } from "fingerprintchrome/puppeteer";
```

Default: `DEMO-KEY` = 1 seat (works out of the box). More seats → ask support → set `FINGERPRINTCHROME_LICENSE_KEY` (same key works on multiple machines).
